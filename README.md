# Create Your Pet

Локальная образовательная игра для практики английского: Present Simple, распорядок дня, целые часы, hobbies и частотные наречия. Для 1–4 учеников на одном устройстве, по очереди. Интерфейс игры — на английском.

## Запуск

Откройте **index.html** двойным кликом в современном Edge, Chrome или Firefox. Интернет, сервер, установка пакетов и аккаунт не нужны. Сохраняйте всю папку проекта вместе: index.html, styles.css и js должны оставаться рядом. Графика уже включена локально, пользовательские изображения не требуются.

1. Выберите число питомцев и режим.
2. Создайте питомца, дайте имя, выберите предметы и комнату.
3. Добавьте 6–10 действий и целые часы. Во втором режиме добавьте 3–6 hobbies с частотой.
4. Сохраните питомца и передайте очередь следующему игроку.
5. Представляйте питомцев по визуальным подсказкам, сравнивайте любую пару.

**Daily Routine** использует только целые часы. **Routine + Hobbies** добавляет always, often, sometimes, never. Готовый профиль показывает короткие правильные предложения, а speaking-режим оставляет ученикам возможность говорить самостоятельно.

## Сохранение

Выборы и черновики автоматически сохраняются в localStorage браузера. При повторном открытии нажмите **Resume game**. Доступность хранения для file:// и приватных окон зависит от браузера; при ограничениях игра сообщает, что данные сохраняются только в текущей вкладке.

Кнопка **Save session** скачивает JSON-файл всей игры, включая черновики. **Open a saved game** на стартовом экране восстанавливает этот файл. Используйте файл для переноса на другой компьютер или как надёжную резервную копию. Перемещение папки, очистка браузерных данных или смена браузера может сделать localStorage старой сессии недоступным.

**Download card** сохраняет полную карточку питомца в PNG. Это изображение для показа или печати, а не файл для восстановления игры. **Edit** изменяет только выбранного питомца. **Start again** требует подтверждения и удаляет сохранённую игру с этого устройства; скачанные файлы остаются.

## Графика и архитектура

104 собственных SVG в assets, готовый локальный реестр js/art.generated.js. Один компоновщик scene используется в превью, профиле, галерее, speaking и PNG. Classic scripts работают без fetch/import и внешних шрифтов. Все данные остаются на устройстве.

Спецификация: [TAMAGOTCHI_GAME_SPEC.md](TAMAGOTCHI_GAME_SPEC.md). Изменения словаря — js/catalog.js; каждое новое действие должно получить explicit grammar mapping и собственную SVG-иконку. Отключайте старые действия через enabled=false, чтобы существующие карточки оставались читаемыми.

## Проверка для разработчика

Нужен Node.js 22+ только для тестов/пересборки графики, не для запуска игры:

```text
node tests/logic.test.mjs
node tests/resilience.test.mjs
node tools/build-art.mjs
```

Браузерные проверки используют встроенный WebSocket Node и Chrome DevTools Protocol без сторонних пакетов. Запустите отдельный Edge/Chrome с `--headless --remote-debugging-port=9223 --allow-file-access-from-files` и отдельной временной папкой `--user-data-dir`, затем `node tests/browser.test.mjs` и `node tests/resilience.test.mjs`. QA проверяет все восемь сочетаний режимов и числа игроков, редактирование/восстановление, шесть пар, отсутствие горизонтального переполнения, PNG-экспорт, клавиатуру, работу без сети, отказ хранения и импорт JSON. Скриншоты по умолчанию пишутся в tests/artifacts; можно переопределить папку переменной PET_QA_ARTIFACTS.

Проверено в локальном Microsoft Edge: 13 групп логических тестов, все восемь учебных сценариев, все шесть пар для четырёх игроков и проверки устойчивости. Проверка с другими браузерами и реальный урок с детьми отдельно не проводились.

Очистку служебного QA browser profile выполняйте отдельно от пользовательского профиля. Публикация и backend в проект не входят.
